# Mi primer proyecto Android

Aplicación Android nativa en Java con español como idioma inicial y selector
persistente para español, inglés, francés y alemán. La pantalla de bienvenida
usa el fondo del PDF de referencia como nine-patch para conservar el marcianito
al adaptarse a diferentes tamaños y orientaciones.

## Abrir y ejecutar

Abre esta carpeta en Android Studio y ejecuta la configuración `app`. También
puedes compilar desde la raíz con `gradlew.bat assembleDebug`.

La aplicación requiere Android 6.0 (API 23) o posterior. En Android 13 y
posteriores, los idiomas también aparecen en los ajustes de idioma por app.
